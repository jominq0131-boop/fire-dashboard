# Milestone 13 — 브랜드 타이포그래피와 앱 셸

## 사용자 문제

기능은 갖춰졌지만 기본 브라우저 메타데이터, 고유 아이콘, 작은 보조 글자와 모바일 상단 메뉴 때문에 범용 업무 도구처럼 보였습니다. 사용자는 토스나 iPhone 앱처럼 세련되고 일관된 제품 인상을 요청했습니다.

## 구현 계약

- fire.의 상승 흐름 마크를 앱 내부, SVG 파비콘,180px Apple touch icon과 manifest에 일관되게 사용합니다.
- 외부 폰트 다운로드 없이 OS 네이티브 산세리프/라운드 계열을 우선하고 일본어 fallback과 고정폭 숫자 기능을 유지합니다.
- 작은 보조 텍스트는 의미가 사라지지 않는 읽기 가능한 크기로 올리고, 제목·본문·숫자의 역할을 타입 스케일로 구분합니다.
- 데스크톱은 사이드바를 유지하고860px 이하는5개 목적지의 하단 탭 바로 전환합니다. safe-area와 콘텐츠 하단 여백을 함께 적용합니다.
- 카드·버튼·입력·선택 상태는 공통 깊이·모서리·포커스·움직임 규칙을 사용하며 reduced-motion 환경에서는 움직임을 줄입니다.
- 금융 계산, 저장 스키마, 기록 상한과 네트워크 동기화는 변경하지 않습니다.

## 검증

메타데이터와3개 아이콘/manifest 응답,180px PNG 크기,5개 모바일 탭의 고정 위치와 아이콘, 최소 글자 크기, 가로 넘침, reduced-motion을 브라우저에서 검사합니다. 기존 연결 차트와 전체 화면 회귀도 함께 확인합니다. 스크린샷에는 합성 데이터만 사용합니다.
