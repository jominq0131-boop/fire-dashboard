# Milestone19 — 한국어 화면과 은퇴 후 소득

## 사용자와 언어

일본 거주 한국인용 앱입니다. 메뉴·입력·오류·접근성·차트·설치 설명은 한국어, HTML/manifest 언어는 ko, 숫자 표시는 ko-KR입니다. 통화는 정수 일본 엔(JPY), NISA·세금 가정은 기존 일본 기준입니다. 원화 환산이나 한국 세제를 적용하지 않습니다. 한국어 네이티브 폰트를 사용하며 사용자 계좌명·메모·ID와 기존 백업은 번역하거나 다시 쓰지 않습니다.

## 소득과 월 계산

월 연금·추가 소득(세후 정수 엔, 0 이상)과 지급 시작 월(도달 후1~1200개월째)을 추가합니다. 1개월째는 목표 달성 다음 달입니다. 시작 월부터 계산 종료까지 고정 명목 금액을 매월 말 현금으로 받습니다. 자동 추정·물가 연동·종료 월·소득 과세 계산은 하지 않습니다. 세금과 보험료를 제외한 수령액을 입력합니다.

주식 수익/생활비 물가를 기존 방식으로 반영하고, 해당 월 소득을 현금에 더한 뒤 현금 우선으로 생활비를 지급합니다. 부족분은 기존 NISA/과세 주식 비례 매도와 원가·세금 계약을 따릅니다. 남는 소득은 현금으로 보관하며 주식에 재투자하지 않습니다. 미래 소득을 당겨 쓰지 않습니다. 소득0은 Milestone18과 같은 결과입니다.

예: 현금120만 엔·생활비 월10만 엔·수익/물가0%는 소득이 없으면13개월째10만 엔 부족입니다. 13개월째부터 세후 소득10만 엔을 받으면24개월을 충당하며 마지막 잔액0엔, 누적 소득120만 엔/생활비240만 엔입니다.

최대1200개월/101점·4시리즈·매도액 탐색 월53회 한도를 유지합니다. 누적 소득도 안전 정수 이하여야 합니다. 잔액·누계 overflow 또는 필요한 원가 미상은 그 월 지급 전 중단하고 직전 완료 월을 표시합니다. 부족 월은 실제 소득과 부분 지급을 기록합니다. 소득으로 생활비가 충당되면 원가 미상으로 중단하지 않습니다.

## 저장과 이행

DB v5 구조와 count/제한 읽기·이전 값 비교·단일 저장 큐는 유지합니다. 목표 입력은21개 문자열(각16 UTF-16 단위), 새 필드는 drawdownIncome="0", drawdownIncomeStart="1"입니다. 구13/15/19필드는 정확한 필드 집합 검증 후 메모리에서만 기본값을 추가합니다. 원본·시각·계좌명·메모는 읽기/내보내기로 바꾸지 않습니다. 편집 commit만21필드를 저장합니다.

JSON v7은21필드를 내보냅니다. v4/v5/v6는 각각13/15/19필드만 허용하며 v1~v3도 읽습니다. 새 소득 설정과 구형 계획이 다르면 금융 기록을 포함한 복원 전체를 취소합니다. 32 MiB와 기존 기록 상한을 유지하며 결과 점/누계는 저장하지 않습니다.

## 검증

한국어 접근성 이름으로 기존 단언을 유지합니다. 지급 시작 경계·소득 없음·초과 소득·미래 차입 금지·물가/세금·원가 미상·안전 정수·구형 이행/원문 보존을 확인합니다. 대표 브라우저에서 한국어/JPY·모바일·결과 무효화·백업/새로고침을 묶어 확인하고 전체 회귀는 최종 CI에 맡깁니다. main/Pages와 공개 대표 흐름까지 확인합니다.
