# 자원과 개인정보 보호

[AGENTS.md](../AGENTS.md)가 운영 규칙의 원본입니다. 실제 금융 기록·백업·비밀값은 코드·테스트·커밋·공개 파일에 포함하지 않습니다.

## 상한

| 대상                | 앱 정책                                                   |
| ------------------- | --------------------------------------------------------- |
| 계좌                | 휴지 포함100, 이름/ID 각각100 UTF-16 단위                 |
| 월별 현금흐름       | 총3600개, 월당1개                                         |
| 잔액                | 총360000개, 월당100개                                     |
| 개요 조회           | 최대12개월/1200잔액·12현금흐름 + 최신 월100잔액 + 계좌100 |
| 현재 계좌 잔액      | 계좌당 역방향 커서 최대2개 확인, 반환 최대100             |
| JSON 문서/병합 결과 | 최대32 MiB UTF-8                                          |
| FIRE 계산           | 최대1200개월, 결과101점                                   |
| 비교/차트           | 비교3개, 각101점; 최대6개 시리즈/606관측점                |
| FIRE 계획 저장      | 단일 계획1개, 비교3개, 입력 문자열당16 UTF-16 단위        |
| 기록 참고 연결      | 시리즈당 최대12관측점/11개 연결 구간, 추가 값 생성 없음   |
| 선택 월 내역        | 이미 조회한 최대100개 잔액                                |

개수는 객체를 읽기 전 트랜잭션 내 count로 확인합니다. 초과 데이터는 삭제/부분 표시하지 않고 명시적으로 실패합니다. JSON은 파일 크기→텍스트 바이트→형식/참조 순서로 검증합니다. 대규모 이력을 시작 시 자동 내보내지 않습니다. 차트 조작은 추가 이력 조회나 금융 계산을 반복하지 않습니다.

## 남는 비용

32 MiB는 브라우저 RAM 보장이 아닙니다. 파싱/복사/현재 자료와 입력 자료가 동시에 메모리에 있을 수 있습니다. DB 인덱스 생성에는 기존 자료량에 따른 시간과 공간이 필요합니다. 외부 코드가 저장한 거대한 단일 객체는 검증 전 읽힐 수 있습니다. 전체 브라우저/확장/운영체제 자원까지 통제한다고 주장하지 않습니다.

## 로컬 실행

실제 브라우저 프로필·사용자 설정·금융 자료를 조사하거나 정리하지 않습니다. 설치된 의존성과 테스트용 브라우저를 재사용하고 전역 설치/환경변수 변경/광범위 프로세스 종료를 하지 않습니다. 합성 데이터와 격리 컨텍스트, 테스트 작업자1개를 사용합니다. 자신이 시작한 서버만 종료합니다. 권한 밖 작업은 정해진 승인 절차를 따릅니다.
