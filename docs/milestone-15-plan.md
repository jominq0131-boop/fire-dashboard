# Milestone 15 — 목표 도달형 FIRE

현재 현금·주식과 저축 추세로 목표금액의 첫 도달 시점과 자산 구성, 자가배당 인출액을 계산합니다. 기존 일괄 자산/물가 조정/비교 계획은 보존합니다.

## 계산 계약

- 시작 월은 계산일의 현재 월이며 첫 적립은 다음 월말입니다. 현금·NISA 적립/성장·과세계좌를 별도로 유지합니다. 증권계좌 현금은 현금으로 분리해서 입력해야 합니다.
- 명시적 불러오기로 기존 제한 조회를 재사용합니다. 최대12개월 창에서 현재 월/미기록을 제외한 완료월 현금흐름 평균을 사용합니다. 현금 저축은 수입-지출-투자 납입입니다. 미기록 월을0으로 처리하지 않습니다. 평균은 정수 엔으로 반올림합니다.
- 기타 자산은 분류 불명으로 제외액을 알립니다. 누락 계좌 수와 기록 시점 차이, 참고한 월들을 표시하고 수정할 수 있습니다. 실제 개인 자료는 테스트하지 않습니다.
- 목표는 고정 명목 금액(기본5000만 엔)입니다. 현금 이자0%, 주식 수익률 기본3%는 수정할 수 있는 예시 가정입니다. 연율/12 월복리, 버킷별1엔 반올림 후 납입합니다.
- NISA 사용량은 평가액으로 추정하지 않습니다. 현재 보유 취득금액 합계/성장 부분과 올해 매수액 두 종류를 직접 입력합니다. 매도 이력이 있을 수 있어 올해 매수액과 현재 보유 취득금액의 단순 대소관계를 강제하지 않습니다.
- 적립/성장 양쪽 적격 상품에 투자 가능하다는 가정하에 적립→성장→과세계좌 순서로 신규 투자합니다. 연간120만/240만, 총 취득1800만/성장1200만 상한을 적용합니다. 매년1월에 연간 사용량을 초기화하며 평가이익은 한도를 소모하지 않습니다.
- 기존 현금 이동, 매도/한도 복원, 과세계좌 매도 후 NISA 재매수, 구NISA는 계산하지 않습니다. 자료: [금융청 NISA](https://www.fsa.go.jp/policy/nisa2/know/), 2026-09-05 확인.
- 최대1200개월을 계산해 최초 도달에서 멈춥니다. 시작점+연별+정확한 도달월 최대101점/6시리즈를 표시합니다. 도달시점 총액과4개 항목의 금액/비율, 구성 막대를 제공합니다.
- 자가배당은 주식 전체 평가액×사용자 인출률(기본 연3%)의 세전 매도액입니다. 연액과 월액은 각각 정수 엔으로 반올림하므로 월액×12와 작은 차이가 있을 수 있습니다. 기업 배당이나 세후 수령액이 아닙니다. 세금/수수료/물가/인출 후 지속성은 모델링하지 않습니다.
- 이미 도달,100년 미도달, 안전 정수 초과, 현금 부족을 구별합니다. 현금 부족을 주식 자동 매도로 감추지 않습니다.

## 저장과 범위

신규 계산 입력/결과는 현재 화면 메모리에만 유지되며 새로고침/JSON 백업 대상이 아님을 화면에 표시합니다. 기존 계획 자동 저장/비교/백업은 그대로입니다. DB v4/JSON v3와 의존성은 변경하지 않았습니다. 신규 계획 영속 저장과 세후/인출 이후 시뮬레이션은 후속 범위입니다.
