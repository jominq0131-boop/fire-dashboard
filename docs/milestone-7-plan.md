# Milestone 7 — 전체 자산, 추이, JSON 백업

2026-09-04 사용자 요청에 따라 Issue #23에서 구현한다. 기존 DB v2/계좌/월별 모델을 유지하며 다음 계약을 적용한다.

1. 전체 개요: 현재 달 이하 최신 잔액 월을 자동 조회하고 합계와 기준 월/입력 계좌 수를 표시한다. 다른 달 상세를 열어도 개요는 유지한다. 누락 계좌의 이전 잔액을 임의로 합치지 않는다. 미래 월은 상세/백업에 보존하지만 현재 자산에서 제외한다.
2. 추이: 종료 월을 기준으로 최대12개월을 표시한다. 기록 없는 달과 금액 범위 초과는 점/연결선을 만들지 않는다. 부분 입력은 흰 점이다. 같은 계좌 집합의 연속 월만 연결·증감을 계산한다. 클릭 시 기존 미저장 입력 경고를 거친 뒤 월별 상세를 읽는다.
3. JSON v1: schemaVersion=1, accounts, monthlyCashFlows, accountBalanceSnapshots를 정규화해 전체 내보낸다. 첫 형식으로 구/미래 버전은 거부한다. 원본 필드/ID/날짜/메모를 보존하며 샘플이나 기본값을 주입하지 않는다.
4. 가져오기: 파일32 MiB/레코드100·3600·360000 한도, 정확한 필드/안전 정수/날짜/유일성/참조를 검증한 뒤 건수 미리보기를 보여준다. 명시적 적용 시 같은 트랜잭션에서 현재 자료를 읽고 비교한다. 동일 자료는 건너뛰고 없는 자료만 추가한다. 같은 ID의 다른 값이나 자연키 충돌은 전체 취소한다. 원본 삭제/덮어쓰기는 제공하지 않으며 빈 브라우저에서 완전 복원할 수 있다.
5. 트랜잭션/자원: 개요는100계좌+최대1200잔액 및 별도 최신월100잔액 이내다. 백업은 명시적 실행에서만 전체를 cursor로 읽으며32 MiB에서 중단·오류 처리한다. 가져오기 병합 결과도 같은 상한이며 초과/실패/동시 충돌은 원본 보존이다. 복원 성공은 commit 후에만 표시한다. 여러 스냅샷/JSON 문자열이 공존하므로 파일 크기와 RAM은 같지 않다.
6. 검증/출시: 순수 도메인 테스트, 격리 Chromium의 다운로드/빈 브라우저 복원/원자성/충돌/경계/기존 회귀, 문서 갱신, PR CI, main CI/Pages, 실제 파일 해시 확인을 수행한다.

전체 데이터가32 MiB를 넘으면 이 버전의 백업 UI는 내보내기를 완료할 수 없다. 자료를 조용히 자르거나 삭제하지 않으며 대용량 스트리밍/덮어쓰기 복원은 후속 설계다. 자동 동기화/외부 서비스/FIRE/PWA는 이번 범위가 아니다.
