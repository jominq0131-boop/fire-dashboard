# Milestone 12 — 연결된 추세와 통일된 제품 디자인

## 사용자 요구

Milestone11의 차트만 어두운 스타일이고 다른 화면은 밝아 통일성이 없었습니다. 누락 월/계좌 구성 변경에서 선을 끊어 여러 기록이 있어도 점만 보일 수 있었습니다. 사용자는 실제 유료 서비스 수준을 기준으로, 별도 세부 지시 없이 연결된 추세와 전체 디자인을 함께 개선하고 배포하도록 요청했습니다. Issue #35에서 추적합니다.

## 구현 계약

- 같은 시리즈의 실제 관측값이2개 이상이면 관측 시점 사이를 선으로 연결합니다. 연속·동일 구성은 실선, 미기록/구성 변경을 건너뛰는 참고선은 점선입니다.
- 참고선은 양끝 기록만 사용합니다. 중간 날짜의 금액을 생성하거나 저장하지 않으며 해당 날짜 툴팁/상세는 미기록 상태를 유지합니다. 계좌 구성 변경을 운용 손익이나 동일 기준 전월 차이로 취급하지 않습니다.
- 자산 합계와 투자 부분 잔액, 수입·소비지출·투자 납입 모두 추세선으로 연결합니다. 막대는 유지하면서 선을 겹칩니다. 계좌 구성 검사는 투자 부분 잔액에도 적용합니다.
- 한 점만 표시되는 범위에는 두 시점 이상의 값이 필요하다는 설명을 제공합니다. 날짜 간 간격은 기존 월/연도 축에 비례합니다.
- theme.css에 공통 배경/표면/글자/강조/오류 색상을 정의하고 내비게이션·카드·폼·표·차트·빈 상태·성공/오류·백업·FIRE에 적용합니다. styles.css의 기존 데이터 크기/반응형 레이아웃 계약은 유지합니다.

## 유지하는 데이터 계약

DB v3/JSON v2, 최대12개월 조회, 금액·날짜·FIRE 계산, 가정의 임시 수명은 그대로입니다. 새 외부 서비스·의존성·동기화 구조는 추가하지 않습니다. 시각적 연결과 계산 가능한 전월 차이는 구분합니다.

## 검증

불연속4개 관측값의 상승·하락/구성 변경, 연속 관측,0/최대 정수, 중간 미기록 유지, 실제 SVG 선 경로를 검증합니다. 기존 단절 검사는 실선의 분리와 명시적 점선 연결을 각각 검사하도록 요구 변경에 맞춰 확장합니다. 전체 섹션을 desktop1440px/mobile320px에서 합성 데이터로 확인하고 극단값/폼/저장/백업 회귀와 PR/main CI/Pages 파일 해시 검증을 수행합니다.
