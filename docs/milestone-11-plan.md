# Milestone 11 — 차트 중심 분석 워크스페이스

## 목표와 완료 기준

사용자가 제공한 financial-os의 시각적 밀도와 복합 그래프를 기준으로, 기능 존재만이 아니라 실제 비교와 확인에 쓸 수 있는 차트를 제공합니다. Issue #33에서 추적합니다.

- 어두운 분석 패널, 읽기 쉬운 축, 충분한 그래프 높이, 일관된 시리즈 색상.
- 자산 면적 + NISA/과세 투자 잔액 막대의 복합 표시. 총자산에 투자 잔액이 포함되며 더하지 않습니다.
- 월 전체 수입/소비지출 막대 + 투자금 납입 선으로 전환. 계좌 필터는 해제됩니다.
- 포인터 툴팁, 터치 선택, 키보드 슬라이더, 시작/종료 범위 확대와 복원.
- 선택 월 기록 합계/같은 계좌의 전월 차이/기록 수와 기존 상세·편집·예측 인계.
- FIRE 시나리오별 같은 색의 자산 면적/목표 파선과 첫 도달 요약.

## 정확성과 범위

기존 monthlyMetrics/monthChange/projectFire 결과를 사용합니다. 투자 분류는 현재 계좌의 nisa_tsumitate/nisa_growth/taxable이며 당시 분류를 복원하지 않습니다. 누락은 0이 아니고, 범위 초과는 표시에서 구별합니다. 합계 계좌 집합이 달라지면 양쪽 관측점은 보존하고 사이의 선·면을 분리합니다. 매월 대표 관측액이므로 운용 손익이나 확정 월말 잔액으로 표현하지 않습니다.

기록 최대12개월, 월당100잔액, 비교3개/6시리즈/각101점 제한을 유지합니다. DB v3/JSON v2와 외부 서비스/동기화 구조, FIRE 가정 수명은 변경하지 않습니다. 전체 테마 전환이나 은퇴 후 인출 모델은 이번 범위가 아닙니다.

## 의존성 결정

Recharts 3.10.0을 고정합니다. 직접 SVG를 유지하는 대안보다 반응형 축·복합 시리즈·툴팁의 구현/유지 비용이 낮습니다. 추가 의존성과 번들 비용이 발생하므로 차트 구현을 동적 청크로 분리하고 npm 감사, 빌드 용량과 실화면을 확인합니다. 계산은 라이브러리에 위임하지 않습니다. 참조: [공식 ComposedChart API](https://recharts.github.io/en-US/api/ComposedChart/).

## 출시 검증

기존 테스트를 유지하며 SVG 구현 교체에 맞춰 선·면 시리즈 선택자를 갱신합니다. 누락/단일0/최대 정수/계좌 변경 단절, 정확한 툴팁, 범위 확대/복원, 수입·투자 비교, 터치와320px/1440px 화면을 합성 데이터로 검사합니다. 로컬·PR CI·main CI·Pages 산출물 확인을 별도로 기록합니다.
