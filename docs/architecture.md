# 아키텍처

## 실행과 저장

React/TypeScript/Vite를 빌드한 정적 파일을 GitHub Pages가 제공합니다. 금융 기록은 각 기기·출처의 IndexedDB에만 저장합니다. 현재 DB v3, JSON 백업 v2입니다. 네트워크 금융 연동·인증·자동 동기화는 없습니다.

## 계층

| 위치               | 책임                                                           |
| ------------------ | -------------------------------------------------------------- |
| src/app            | 화면 구성, 의존성 주입, 기록 → 예측 이동                       |
| src/features       | 계좌·월별·백업·FIRE UI, 임시 입력과 차트 선택                  |
| src/domain         | 정수 엔·날짜·레코드 검증, 계산, 저장소 계약, 마이그레이션 계획 |
| src/infrastructure | IndexedDB 트랜잭션과 제한 조회·추가 복원                       |
| src/main.tsx       | 실제 어댑터 조립                                               |

도메인은 React·IndexedDB·네트워크를 import하지 않습니다. UI는 계약을 통해서만 저장소에 접근합니다.

## 읽기·쓰기 흐름

계좌/월별 읽기는 트랜잭션 내 count 검사 후 제한 조회합니다. 생성/수정의 성공은 요청 성공이 아니라 commit 이후입니다. 기존 값을 비교해 다른 탭의 변경을 덮어쓰지 않고, 실패 시 입력과 저장 자료를 보존합니다. 연결은 완료·실패·versionchange 때 닫습니다.

PortfolioRepository는 동일한 읽기 트랜잭션에서 최대 12개월 잔액·현금흐름 이력, 최신 잔액 기록 월, 계좌별 마지막 기록을 반환합니다. 계좌당 역방향 인덱스 커서는 최대 2개를 확인합니다. 화면은 성공한 기록을 재조회하며 탭 간 자동 동기화는 없습니다.

BackupRepository는 크기/개수/참조/충돌을 검증하고 한 트랜잭션에서 누락된 레코드만 추가합니다. clear/delete/덮어쓰기는 없습니다.

## 차트 → 상세 → 예측

HistoryExplorer는 이미 조회한 최대 12개월을 6·12개월/계좌 필터로 표시합니다. 추가 전체 이력 조회 없이 선택 월의 계좌 내역과 현금흐름을 보여줍니다. 입력 화면 이동은 기존 미저장 변경 확인을 유지합니다.

선택 기록액의 예측 이동은 App의 명시적 핸들로 연결합니다. FirePlanner는 기존 입력이 있으면 시작 금액 교체를 확인하고, 다른 가정과 비교 항목은 보존합니다. 현재 예측 결과만 무효화하며 저장 데이터에는 쓰지 않습니다.

InteractiveLineChart는 Suspense 로딩 경계이며 FinancialChart를 동적 청크로 불러옵니다. FinancialChart는 Recharts 3.10.0의 반응형 복합 차트, 툴팁, 면적/막대/선, 범례와 키보드 슬라이더, 범위 확대를 제공하는 표시 계층입니다. line-geometry의 seriesSegments는 비교 가능한 실선 구간을 분리하고 observationBridges는 누락/구성 변경을 가로지르는 실제 두 관측값 사이의 점선 참고 경로를 반환합니다. 중간 값은 생성하지 않습니다. 막대에도 추세선을 겹칩니다. 라이브러리는 금융 계산이나 저장을 하지 않습니다.

HistoryExplorer는 기록 합계와 현재 NISA/과세 계좌 분류의 부분 합계를 복합 표시합니다. 부분 합계도 monthlyMetrics로 검증·계산합니다. 월 전체 수입/지출/투자 납입 비교로 전환하면 계좌 선택을 해제합니다. 확대는 이미 읽은 데이터를 잘라 표시하므로 추가 DB 조회가 없습니다.

ProjectionChart는 검증된 FireProjection의 연도별 점을 재사용합니다. 현재 가정은 2개 시리즈, 비교는 최대 6개 시리즈이며 각 시리즈는 최대 101점입니다. 시나리오별 같은 색의 자산 면적/목표 파선과 첫 도달 요약을 표시합니다. 수정하면 현재 결과를 숨기고 비교 스냅샷은 유지합니다.

## 레이아웃

styles.css는 기존 레이아웃/크기 경계를, 이후 로드하는 theme.css는 공통 디자인 토큰과 화면별 색상 상태를 관리합니다. 배경/표면/텍스트/민트 강조/오류 토큰을 내비게이션·폼·표·차트·빈 상태·알림 전체에 적용합니다. 새 UI는 공통 토큰을 따르고 섹션 간 일관성을 검증합니다.

차트 모듈 다운로드/렌더링 오류는 ChartBoundary 내부에 표시하며 계좌·기록 폼은 유지합니다. 재시도 안내는 저장 후 새로고침을 명시합니다. 로딩 표시는 aria-busy를 사용하며 기록 저장 알림과 구별합니다.

이름·값·동작 영역을 분리하고 숫자는 자릿수 정렬을 사용합니다. 긴 문구는 세로로 줄바꿈하며 표는 내부에서 가로 스크롤합니다. 금액을 잘라 숨기거나 페이지 전체 overflow를 감추지 않습니다. 모바일 배치는 화면 폭에 따라 바뀝니다.
