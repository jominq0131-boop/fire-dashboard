# FIRE Dashboard

일본 거주자를 위한 개인 자산 기록·비교·FIRE 시뮬레이션 웹 앱입니다. [앱 열기](https://jominq0131-boop.github.io/fire-dashboard/)

## 할 수 있는 일

- 계좌를 등록하고 확인한 날짜의 잔액을 기록합니다. 월말을 놓쳐도 오늘부터 다시 시작할 수 있습니다.
- 계좌별 마지막 잔액으로 전체 금융자산을 보고, 오래되거나 누락된 기록을 확인합니다.
- 월별 자산 면적·투자 잔액 막대를 겹쳐 보고, 수입·지출·투자 납입 비교로 전환합니다. 툴팁과 마우스·터치·키보드 선택으로 상세를 확인합니다.
- 선택한 기록액을 FIRE 시작 금액으로 가져와 목표·적립액·수익률·물가상승률을 직접 설정합니다.
- 예측 자산 면적과 목표 파선을 최대 3개 시나리오로 비교하고, 첫 도달 요약과 기간 확대를 사용합니다.
- JSON 백업을 내려받고 검증·미리보기 후 기존 기록을 보존하며 복원합니다.

## 사용 순서

1. **계좌 관리**에서 계좌 이름과 종류를 등록합니다.
2. **오늘의 잔액 기록**에서 실제 확인일과 금액을 입력합니다. 수입·소비 지출·투자 납입은 월별로 별도 입력합니다.
3. **자산의 추이**에서 전체/개별 계좌와 6·12개월을 선택합니다. 차트 위에서 정확한 금액을 확인하고 시작/종료 범위로 확대합니다. **수입·지출 비교**로 전환하면 월 전체 흐름을 볼 수 있습니다. 차트 또는 슬라이더로 월을 고르면 상세가 바뀝니다.
4. **선택 월의 입력·편집**으로 기록을 수정하거나 **이 기록액으로 FIRE 시산**으로 예측에 연결합니다.
5. **FIRE 시뮬레이션**을 계산하고 10·30·100년 그래프에서 연도를 선택합니다. 범례로 선을 켜고 끄며, 비교에 추가한 가정은 다음 입력과 독립적으로 유지됩니다.
6. **백업과 복원**에서 정기적으로 JSON 파일을 보관합니다.

## 숫자의 의미와 저장

전체 자산은 계좌마다 확인 날짜가 다른 마지막 기록의 합계이며 실시간 평가액이나 순자산이 아닙니다. 한 계좌는 한 달에 대표 잔액 하나를 저장합니다. 누락 월은 0으로 채우지 않습니다. 전체 합계의 선과 전월 비교는 동일한 계좌가 기록된 연속 월에서만 연결합니다.

투자 잔액 막대는 전체 자산에 이미 포함된 현재 NISA·과세 투자 분류 계좌의 기록액입니다. 월별 투자 납입과 구분합니다. 기록의 증감에는 입출금도 포함되므로 운용 손익으로 해석하지 않습니다.

금융 기록은 이 사이트의 브라우저 IndexedDB v3에 저장합니다. JSON v2로 내보내며 v1도 가져올 수 있습니다. 자동 동기화는 없습니다. 브라우저 데이터를 지우면 기록을 잃을 수 있습니다. FIRE 가정·비교는 임시 화면 상태라 새로고침하면 사라지고 백업에 포함되지 않습니다.

FIRE 결과는 사용자가 입력한 일정한 가정에 따른 계산입니다. 세금·수수료·부채·인출 이후의 유지 가능성·시장 변동을 모델링하지 않습니다. 자세한 의미는 [데이터 모델](docs/data-model.md)을 따릅니다.

## 개발과 문서

React · TypeScript · Vite · Recharts 정적 앱입니다. 차트 라이브러리는 고정 버전과 동적 청크로 관리합니다. 최초 준비 또는 lockfile 변경 시 `npm ci`, 개발 서버는 필요할 때 `npm run dev`를 실행합니다.

```sh
npm run format
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
```

동일 코드의 통과한 로컬 검증은 재사용하고, 최종 PR CI·main CI·실제 배포를 확인합니다. 실제 금융 기록·백업·비밀값은 저장소나 배포 파일에 넣지 않습니다.
